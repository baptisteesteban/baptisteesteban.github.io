#### Head of EPITA Image Major

Since February 2025, I have been co-head of the EPITA Image Major. I am in
charge of the pedagogical content of the specialization, but I also handle other
activities such as end-of-study projects with companies, in which students work
in groups with a company on a project for one year, or the grading of
end-of-study internship reports and defenses.

#### MedViz

MedViz is a project I supervise with [Azéline
Aillet](https://fr.linkedin.com/in/azeline-aillet) and [Anaïs
Liné](https://fr.linkedin.com/in/ana%C3%AFs-lin%C3%A9-3134b81b6) over the first
semester of the EPITA Image Major. The goal of the project is to conceptualize,
design, and implement a SaaS medical imaging software. The project is organized
around several coaching sessions and defenses. At the end of the project,
students are required to deliver a professional project, including the
documentation and the software release process.

#### Python Refresher

This course provides a brief refresher on the Python programming language for
scientific computing. It covers the [array
programming](https://en.wikipedia.org/wiki/Array_programming) paradigm, Big Data
processing with [Pandas](https://pandas.pydata.org/), efficient Python
programming using [JIT compilation with Numba](https://numba.pydata.org/), and
Python multi-service applications.

#### Introduction to Deep Learning

This course is an introduction to deep neural networks. It covers generic
automatic differentiation, multi-layer perceptrons, convolutional neural
networks (CNNs), and residual networks. Furthermore, different training
strategies, as well as regularization methods, are studied. Finally, neural
networks are applied to various tasks such as image classification and
segmentation using [PyTorch](https://pytorch.org/).

#### Advanced C++

This course introduces good practices using modern C++ features (C++ 20 and
beyond), with a strong focus on generic programming. Studied concepts include
constrained genericity, ranges, and type erasure.
